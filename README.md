# Telegram-бот «Анонимные знакомства» (Find a Friend)

**⚠️ СТАТУС ПРОЕКТА: НЕ ЗАКОНЧЕН **
Проект представляет собой рабочий каркас (MVP) с базовой структурой базы данных и интерфейсом, но ключевая логика (обмен сообщениями между собеседниками и сохранение профиля) не дописана.

Telegram-бот на базе aiogram (v3), предназначенный для анонимного поиска собеседников по интересам. Пользователи создают профиль, указывают свои увлечения и возраст, а затем бот подбирает им случайного собеседника из базы активных пользователей.

## 🤝 Основной функционал (Реализовано частично)

### Для пользователей:
- Онбординг: При первом запуске бот просит заполнить профиль (имя, возраст, информация о себе, интересы).
- Поиск собеседника: Случайный подбор пользователя из базы (не реализованно).
- Профиль: Просмотр и редактирование данных (не реализованно).
- Внутренняя валюта: Заработок «звезд» за приглашенных рефералов (+3 за друга).
- Промокоды: Активация промокодов для получения бонусов.

### Для администраторов:
- Панель управления: Доступ по команде /admin.
- Управление валютой: Ручное начисление и списание звезд пользователям по ID.
- Рассылки: Отправка сообщений всем пользователям или только тем, кто не привел рефералов.
- Управление каналами: Добавление/удаление ID каналов для обязательной подписки.
- Промокоды: Создание и деактивация промокодов.

## 📂 Структура проекта

```text
├── main.py               # Основной файл бота (роутеры, хэндлеры, логика поиска)
```

## 🛠️ Установка и запуск

### 1. Установка зависимостей
Убедитесь, что у вас установлен Python 3.10 или выше.

pip install aiogram

### 2. Настройка settings.py
Откройте файл settings.py и укажите свои данные:
- TOKEN — токен бота (от @BotFather).
- channel_ids — список ID каналов для обязательной подписки.
- admins — список ID администраторов.

### 3. Запуск
При первом запуске автоматически создастся файл database.db и все необходимые таблицы. Запустите бота командой:

python main.py

## ⚠️ Что нужно доделать (Known Issues)

1. **Обмен сообщениями:** В функции обработки кнопки "🔎Искать собеседника" логика обрывается. Бот находит пользователей в статусе поиска, но механизм пересылки сообщений между ними (создание анонимного чата) не реализован.
2. **Сохранение профиля:** В классе `UserState` есть шаги для ввода имени, возраста и интересов, но обработчик `set_user_info` не сохраняет введенные данные в базу и не завершает онбординг.
3. **Смешение версий aiogram:** В конце файла main.py находится строка `executor.start_polling(...)`. Это синтаксис из aiogram 2.x, он не работает в aiogram 3.x и подлежит удалению.
4. **Безопасность:** Токен в файле settings.py находится в открытом виде. Для реальной работы сгенерируйте новый токен и используйте .env файл.
